### What is MISSING (blockers for go-live)

1. **NOT DEPLOYED** — No infrastructure has been deployed to AWS
2. **Hardcoded secrets** — Admin password and session secret are hardcoded in Lambda code
3. **No custom domain** — Will use CloudFront default domain initially
4. **No SES/SQS for notifications** — Leads go to DynamoDB but no email notification
5. **Backoffice quote creation** — The contact form on landing creates leads, but there's no endpoint to create quotes from the pricing plan selection
6. **E2E tests** — Cannot run until infrastructure is deployed

### Key Decisions Made

1. **Auth approach**: CloudFront Function only does SPA routing (no cookie validation). Real auth is at API level via Bearer token + HMAC. This is deliberately simple for MVP.
2. **No framework**: Backoffice SPA is vanilla JS (no React/Vue) to keep it dependency-free and fast to deploy.
3. **Single Lambda**: All endpoints share one Lambda to keep deployment simple. Can split later if needed.
4. **Soft-delete**: Products use status="deleted" rather than actual deletion.
